# ТВ-Доктор

Приложение для Android-телефона, которое подключается к Android-телевизору по домашней сети
и выясняет, почему он тормозит, а затем помогает это исправить. Root на телевизоре не нужен.

Телефон общается с телевизором через **ADB** (Android Debug Bridge) — штатный отладочный
канал Android. Его нужно один раз включить в настройках телевизора.

## Возможности

| Вкладка | Что делает |
|---|---|
| **Обзор** | Память, процессор, температура, флеш-память, автозапуск; выводы простым языком с кнопками исправления; оценка 0–100 и сравнение с прошлым замером; тест скорости памяти |
| **Загрузка** | Перезагружает ТВ и замеряет время; разбирает этапы загрузки по журналу; кто запускается при старте и грузит процессор |
| **Приложения** | Сколько памяти и места занимает каждое приложение; запрет фона, остановка, отключение, замер холодного запуска; блок «Отключённые — можно вернуть» |
| **Обслуживание** | TRIM памяти, оптимизация приложений, очистка кэша, закрытие фона, поиск больших файлов, проверка обновлений прошивки |
| **Терминал** | Любые команды `adb shell`, справочник готовых команд, разбор «что открывается при включении» |

Результаты можно выгрузить: текстом в мессенджер, файлом, в папку «Загрузки» или в буфер обмена.

## Установка

1. На телефоне откройте раздел **Releases** этого репозитория.
2. Скачайте последний файл `TV-Doctor-N.apk`.
3. Откройте его и разрешите установку из этого источника.

Новые версии ставятся поверх старых, настройки сохраняются.

## Подготовка телевизора (один раз)

1. **Настройки → Об устройстве (Система → О системе)** → 7 раз нажмите «Сборка». Появится режим разработчика.
2. **Настройки → Для разработчиков** → включите **«Отладка по сети»** (на некоторых ТВ — «Беспроводная отладка»). Если ни того ни другого нет — включите **«Отладка по USB»**: на телевизорах она обычно открывает сетевой порт 5555.
3. Узнайте IP-адрес ТВ: **Настройки → Сеть** → ваша сеть.
4. Телефон и ТВ должны быть в одной сети. VPN на телефоне на время подключения лучше выключить.

## Первое подключение

1. Введите IP-адрес ТВ и порт (обычно `5555`) и нажмите **«Подключиться»**.
2. На экране ТВ появится запрос «Разрешить отладку» — нажмите **«Разрешить»** и отметьте **«Всегда»**.
3. Если на ТВ «Беспроводная отладка» (Android 11+), сначала выполните **сопряжение по коду**
   (см. [инструкцию](docs/user-guide.md#сопряжение-по-коду)).

Не получается? Кнопки **«Проверить связь»** и **«Найти ТВ в сети»** подскажут причину.
