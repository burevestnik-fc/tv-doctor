# ТВ-Доктор

Приложение для Android-телефона, которое подключается к Android-телевизору по сети (ADB)
и выясняет, почему он тормозит: память, износ флеш-памяти, нагрузка, автозапуск,
подробный разбор этапов загрузки.

## Что умеет

- **Обзор:** свободная встроенная и оперативная память, нагрузка процессора, температура,
  износ eMMC (если прошивка отдаёт), кто занимает процессор, кто подписан на автозапуск.
  Итоговые выводы простым языком.
- **Загрузка:** перезагружает ТВ, замеряет время, читает журнал загрузки и показывает
  этапы (ядро → Android → сканирование приложений → системные службы → экран),
  что запускалось при старте, кто съел процессор, ошибки памяти в журнале ядра.
- **Приложения:** занимаемая память и место, автозапуск; остановить, отключить/включить,
  замерить холодный запуск, очистить кэш всех приложений.
- **Терминал:** любые команды `adb shell`.
- **Отчёт:** файлом (в Telegram, почту) или кратко в буфер обмена.

## Сборка

APK собирается автоматически в GitHub Actions при каждом изменении кода.
Готовый файл — в разделе **Releases** репозитория (или во вкладке **Actions** → сборка → Artifacts).

## Подготовка телевизора

1. Настройки → Об устройстве → 7 раз нажать «Сборка» — включится режим разработчика.
2. В «Для разработчиков» включить «Отладку по сети» (или «Беспроводную отладку»).
3. Там же: «Размер буфера журнала» — максимум.
4. Узнать IP-адрес ТВ: Настройки → Сеть.
5. При первом подключении на ТВ нажать «Разрешить» и отметить «Всегда».
