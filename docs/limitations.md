# Ограничения и известные проблемы

## Что невозможно без root

ТВ-Доктор работает с правами пользователя `shell`, которые даёт ADB. Этого хватает на диагностику
и большинство настроек, но не на всё.

| Нельзя | Почему | Что вместо |
|---|---|---|
| Отключить отдельный компонент приложения (службу, приёмник автозапуска) | С Android 10–11 оболочке разрешено менять состояние только целых пакетов — у любых приложений, не только системных (`Shell cannot change component state`) | Отключить пакет целиком (`pm disable-user`) — только если в нём нет важных функций |
| Убрать приложение из автозапуска, не отключая его | Приёмник загрузки срабатывает и при запрете фона | Запрет фона (не даёт работать в фоне) или отключение приложения |
| Прочитать прямой показатель износа eMMC | Прошивка закрывает `life_time` / `pre_eol_info` | Тест скорости памяти |
| Читать журнал ядра (`dmesg`) | Закрыт на многих прошивках | Журнал Android (`logcat`) |
| Проверить обновления прошивки с телефона | У производителя нет открытого способа | Кнопка открывает проверку на экране ТВ |
| Удалять файлы из `Android/data`, `Android/obb` | Специально запрещено в приложении: ломает приложения и игры | — |
| Замерить загрузку от момента нажатия кнопки питания | Сеть и ADB появляются только в середине загрузки | Этапы восстанавливаются по журналу ТВ задним числом |

## Особенности платформ MStar/MediaTek

- **Средняя нагрузка всегда высокая** (у Hyundai AI Point ≈ 59) из-за драйверов, вечно ждущих событий железа
  в состоянии D. ТВ-Доктор это учитывает, но сторонние приложения-«оптимизаторы» на такой ТВ будут врать.
- **Пакеты производителя** (`com.homwee.*`, `com.mediatek.*`, `com.gdch.*`) содержат сервисное меню и сброс.
  Их нельзя запускать вслепую — только изучать через `dumpsys`.
- **Отельный режим Homwee** при холодной перезагрузке открывает тюнер вместо главного экрана (см. [findings.md](findings.md#7-поиск-каналов-вместо-главного-экрана-после-перезагрузки)).

## Зависит от прошивки

- Датчики температуры могут отсутствовать.
- `top` на старых прошивках может не поддерживать `-o` — тогда используется формат по умолчанию.
- Метки этапов загрузки в журнале событий есть не на всех ТВ; если журнал маленький, начало загрузки вытесняется
  (поэтому «Перезагрузить и измерить» увеличивает журнал до 16 МБ).
- Программа обновления производителя может называться по-разному; ТВ-Доктор ищет пакеты со словами `upgrade`, `update`, `ota`, `fota`.
- Дата «последнего обслуживания» системы берётся из `dumpsys mount`; на некоторых прошивках строки нет — тогда «нет данных».

## Связь

- **Нет пункта «Беспроводная отладка»** (Android 10–11 на многих ТВ): включите **«Отладка по USB»** — на телевизорах она обычно открывает сетевой порт 5555.

- **«Беспроводная отладка»** (Android 11+) выключается при каждой перезагрузке ТВ и получает новый порт.
  Её нужно включить снова на ТВ; новый порт приложение найдёт само через mDNS. «Отладка по сети» на порту 5555
  такой проблемы не имеет.
- **VPN на телефоне** часто блокирует доступ к устройствам домашней сети.
- **VPN на телевизоре** может сообщать неверный IP-адрес ТВ.
- Тайм-аут одной команды — 90 секунд. Долгие операции (оптимизация приложений) запускаются на ТВ в фоне.

## Точность замеров

- **Тест памяти** — ориентир, а не лабораторный замер: время меряет телефон (сетевая задержка мала на фоне секунд),
  ТВ в это время может что-то делать. Сравнивайте замеры, сделанные в одинаковых условиях.
- **Нормы** («20–80 МБ/с», «до 10–15 мс») — ориентировочные для eMMC в телевизорах, не паспортные значения конкретной микросхемы.
- **«Замер телефоном»** при перезагрузке включает выключение ТВ и ожидание сети, поэтому всегда больше реальной загрузки.
- **Дата последнего запуска приложений** берётся из статистики Android и может отсутствовать.

## Известные недочёты

- В окне подтверждения отключения приложений показываются имена пакетов, а не понятные названия.
- Понятные названия и оценки есть только для приложений из справочника (`KnownApps.kt`); остальные оцениваются
  по имени пакета («Стороннее приложение», «VPN», «Игра»…). Для удалённых системных пакетов это может быть неточно.
- Галочки и найденные большие файлы не сохраняются после закрытия приложения.
- Нормы для «Процессор перегружен» (≥ 75%) и порогов памяти подобраны по опыту, а не по стандарту.

## Идеи на будущее

- Попробовать скрыть вход тюнера через `settings put secure tv_input_hidden_inputs`.
- Понятные названия приложений в окнах подтверждения.
- Расширить справочник `KnownApps` популярными в России ТВ-приложениями.
- Сохранять в историю результаты замеров холодного запуска приложений.
